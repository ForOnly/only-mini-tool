## 1. 技术选型

### 1.1 前端技术栈

| 模块 | 选型 | 版本 | 理由 |
|---|---|---|---|
| 框架 | **Vue 3** | 3.5.x | Composition API + `<script setup>`，组合式逻辑复用 |
| 构建 | **Vite** | 6.x | 与 Vue 3 深度集成，Tauri 官方模板即用 Vite，HMR 快 |

## 3. OCR 引擎抽象（核心设计）

### 3.1 设计决策：引擎在哪里跑？

**引擎调度与执行全部放 Rust 后端**，前端只做配置与展示。

```
Vue 前端                          Tauri IPC                    Rust 后端
┌──────────────────┐  invoke()  ┌──────────────┐  dispatch   ┌───────────────────────┐
│ ocr/registry.ts  │ ─────────▶ │ #[tauri::cmd]│ ──────────▶ │ trait OcrEngine        │
│ (仅元信息/配置UI) │            │ ocr::recognize│             │   BaiduEngine         │
│ ocr.store.ts     │ ◀───────── │  返回归一化   │ ◀────────── │   (将来) TencentEngine│
└──────────────────┘  OcrResult │  serde JSON  │             │   TesseractEngine     │
                                └──────────────┘             └───────────────────────┘
```

**为什么放 Rust：**
1. **密钥安全**：API Key/Secret 由 Rust 读取配置，绝不出现在前端 JS；OAuth 取 access_token 全程在 Rust 内完成；
2. **网络层封装**：reqwest 异步调用各厂商 REST 端点，Rust 内把厂商原始响应归一化成统一 `OcrResult`；
3. **本地引擎潜力**：未来接 Tesseract / rust-ocr（纯本地）时，文件 IO 与线程在 Rust 更自然，无需经 IPC 传超大图片字节；
4. **结果结构统一**：所有引擎在 Rust 端产出同一 serde 结构，前端拿到稳定归一化结果，前端永不改。

**前端 `src/ocr/` 仅存引擎元信息**：引擎 ID、显示名、配置表单 schema、是否需要密钥，用于渲染「引擎选择」下拉与「密钥输入」表单。**前端不做实际识别**。

### 3.2 前端类型契约（`src/ocr/types.ts`）

```ts
// 归一化坐标：图片像素坐标系
export interface OcrRect {
  left: number      // 相对图片左上角
  top: number
  width: number
  height: number
}

export interface OcrWord {
  text: string
  rect: OcrRect
  confidence: number   // 0~1；引擎不提供时归一化为 1

export interface OcrResult {
  engine: string            // 实际使用引擎 id

  raw?: unknown             // 引擎原始响应（调试用）

  configSchema: OcrConfigField[]

  key: string       // 'apiKey' | 'secretKey' | 'tesseractLang'
```

### 3.3 Rust 端抽象（`src-tauri/src/ocr/`）

`engine.rs` — 引擎 trait 与错误：

```rust
use serde::{Deserialize, Serialize};

#[derive(Clone, Copy, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum EngineKind { Cloud, Local }

#[derive(Debug, thiserror::Error)]
pub enum OcrError {
    #[error("OCR 引擎未配置: {0}")]
    NotConfigured(String),
    #[error("引擎调用失败: {0}")]
    Engine(String),
    #[error("网络错误: {0}")]
    Network(#[from] reqwest::Error),
    #[error("图片读取失败: {0}")]
    Image(#[from] std::io::Error),
    #[error("配置错误: {0}")]
    Config(String),
}

#[async_trait::async_trait]
pub trait OcrEngine: Send + Sync {
    fn id(&self) -> &'static str;
    fn kind(&self) -> EngineKind;
    /// 该引擎需要的机密字段（如 apiKey/secretKey）
    fn required_secrets(&self) -> Vec<&'static str>;

    /// 核心识别：输入图片字节 + 配置，返回归一化结果
    async fn recognize(&self, image: Vec<u8>, cfg: &EngineConfig) -> Result<OcrResult, OcrError>;
}
```

`registry.rs` — 引擎注册表（dispatch）：

```rust
pub struct OcrRegistry {
    engines: HashMap<&'static str, Box<dyn OcrEngine>>,
    active: String,
}

impl OcrRegistry {
    pub fn new(active: String) -> Self {
        let mut e = HashMap::new();
        e.insert("baidu", Box::new(BaiduEngine) as Box<dyn OcrEngine>);
        // 将来： e.insert("tencent", Box::new(TencentEngine));
        //       e.insert("tesseract", Box::new(TesseractEngine));
        Self { engines: e, active }
    }

    pub async fn recognize(&self, image: Vec<u8>, cfg: &EngineConfig) -> Result<OcrResult, OcrError> {
        let engine = self.engines.get(self.active.as_str())
            .ok_or_else(|| OcrError::NotConfigured(self.active.clone()))?;
        engine.recognize(image, cfg).await
    }

    pub fn active_engine(&self) -> &str { &self.active }
}
```

`engines/baidu.rs` — 百度引擎实现（复刻旧 `access.py` + `baidu_ocr_handwriting`）：

```rust
pub struct BaiduEngine;

impl OcrEngine for BaiduEngine {
    fn id(&self) -> &'static str { "baidu" }
    fn kind(&self) -> EngineKind { EngineKind::Cloud }
    fn required_secrets(&self) -> Vec<&'static str> { vec!["apiKey", "secretKey"] }

    async fn recognize(&self, image: Vec<u8>, cfg: &EngineConfig) -> Result<OcrResult, OcrError> {
        let api_key = cfg.secret("apiKey").ok_or(OcrError::NotConfigured("apiKey".into()))?;
        let secret = cfg.secret("secretKey").ok_or(OcrError::NotConfigured("secretKey".into()))?;

        // 1) OAuth 获取 access_token（旧 access.get_access_token）
        let token = self.get_access_token(api_key, secret).await?;

        // 2) base64 编码图片（旧 base64.b64encode）
        let b64 = base64::engine::general_purpose::STANDARD.encode(&image);

        // 3) POST handwriting（旧 baidu_ocr_handwriting）
        let client = reqwest::Client::new();
        let resp = client
            .post(format!("https://aip.baidubce.com/rest/2.0/ocr/v1/handwriting?access_token={token}"))
            .header("content-type", "application/x-www-form-urlencoded")
            .form(&[("image", b64)])
            .send().await?
            .json::<serde_json::Value>().await?;

        if let Some(code) = resp.get("error_code") {
            return Err(OcrError::Engine(format!("百度错误 {code}: {}", resp["error_msg"])));
        }

        // 4) 归一化：words_result[{location:{left,top,width,height}, words}]
        let mut words = Vec::new();
        for (i, item) in resp["words_result"].as_array().unwrap_or(&vec![]).iter().enumerate() {
            let l = &item["location"];
            words.push(OcrWord {
                text: item["words"].as_str().unwrap_or("").to_string(),
                rect: OcrRect {
                    left:  l["left"].as_i64().unwrap_or(0) as i32,
                    top:   l["top"].as_i64().unwrap_or(0) as i32,
                    width: l["width"].as_i64().unwrap_or(0) as i32,
                    height: l["height"].as_i64().unwrap_or(0) as i32,
                },
                confidence: 1.0,   // 百度 handwriting 不返回 confidence，归一化为 1
                line: i as i32,    // 暂按返回顺序，后续可按 top 聚类
            });
        }
        let text = words.iter().map(|w| w.text.as_str()).collect::<Vec<_>>().join("\n");
        Ok(OcrResult { engine: "baidu".into(), words, text })
    }
}

impl BaiduEngine {
    async fn get_access_token(&self, api_key: &str, secret: &str) -> Result<String, OcrError> {
        let resp = reqwest::Client::new()
            .post("https://aip.baidubce.com/oauth/2.0/token")
            .form(&[("grant_type", "client_credentials"),
                    ("client_id", api_key),
                    ("client_secret", secret)])
            .send().await?
            .json::<serde_json::Value>().await?;
        resp.get("access_token").and_then(|t| t.as_str())
            .map(|s| s.to_string())
            .ok_or_else(|| OcrError::Engine("获取 Access Token 失败".into()))
    }
}
```

**新增引擎扩展方式（关键需求落地）**：三步即可
1. 新建 `src-tauri/src/ocr/engines/xxx.rs`，实现 `OcrEngine` trait；
2. 在 `registry.rs::new()` 里 `e.insert("xxx", Box::new(XxxEngine))`；
3. 前端 `src/ocr/engines/index.ts` 注册对应 descriptor 与配置表单。
**前端核心 UI、IPC、结果面板一行不改。**

### 3.4 Tauri IPC 接口（`src-tauri/src/commands/ocr.rs`）

```rust
#[tauri::command]
async fn recognize(
    app: tauri::AppHandle,
    image: Vec<u8>,            // 前端传图片字节（base64 解码后）
) -> Result<OcrResult, String> {
    // 从插件 store 读 activeEngine + 该引擎密钥
    let cfg = config::load_engine_config(&app).map_err(|e| e.to_string())?;
    let registry = OcrRegistry::new(cfg.active_engine);
    registry.recognize(image, &cfg).await.map_err(|e| e.to_string())
}

#[tauri::command]
async fn set_config(app: tauri::AppHandle, engine: String, secrets: HashMap<String, String>) -> Result<(), String> {
    config::save_engine_config(&app, &engine, secrets).map_err(|e| e.to_string())
}

#[tauri::command]
async fn get_config(app: tauri::AppHandle) -> Result<EngineConfig, String> {
    config::load_engine_config(&app).map_err(|e| e.to_string())
}

#[tauri::command]
async fn fix_orientation(image: Vec<u8>, angle: u32) -> Result<Vec<u8>, String> {
    image::fix_orientation(&image, angle).map_err(|e| e.to_string())
}
```

**IPC 设计要点**：
- **输入**：前端把图片转 base64 传入 `recognize`；密钥**不**经过前端，Rust 从 store 内部读取；
- **输出**：`OcrResult` 直接 serde 序列化为 camelCase JSON 返回（Vue 侧 `invoke('recognize')` 拿到 typed 对象）；
- **错误**：`Result<_, String>`，Rust 内 `OcrError` 用 thiserror 转成中文可读信息，前端 store 捕获后 toast；
- **异步**：`async fn` command 跑在 tokio 上，等价旧 `QThread`（OcrHandler），不阻塞 UI；
- **图片字节**：数据量大时用 base64 字符串（IPC 原生支持），前端 `ArrayBuffer → base64`。

**配置流向**：
```
settings.store → invoke('set_config', {engine:'baidu', secrets:{apiKey,secretKey}})
              → tauri-plugin-store 落盘
识别时: settings.store.activeEngine + 图片 → invoke('recognize')
       → Rust 读 store 取密钥 → 建 BaiduEngine → reqwest 调用
```

```ts
const useOcrStore = defineStore('ocr', {

  actions: {
    async loadImage(src: string) {           // 文件/粘贴/拖放统一入口
      this.imageDataUrl = src
      await this.recognize()
    },
    async recognize() {
      this.loading = true
      try {
        const bytes = await dataUrlToBase64(this.imageDataUrl!)
        const res = await invoke<OcrResult>('recognize', { image: bytes })
        this.result = res
        this.fullText = res.text
      } catch (e) { this.error = ... }
      finally { this.loading = false }
    },
    copyWord(word: OcrWord) { /* 写剪贴板 + 入 copyLog */ },
    copyAll() { /* 写全文 + 入 copyLog */ },
    reset() {}, clear() {}, setZoom(z) {}, toggleBoxes() {},
  },
})
```

### 4.3 识别框坐标映射（缩放/平移下对齐，关键算法）

旧 QML 方案：`ocrLayer` 与图片 painted 尺寸相同、随 `image.zoom` 缩放，box 直接填 `location` 像素坐标。Vue 用 **CSS transform 同层同 scale** 复刻：

```html
<!-- 图片与 overlay 共享同一个变换坐标系 -->
<div class="image-stage" :style="{ transform: `scale(${zoom})`, transformOrigin: '0 0' }">
  <img :style="{ width: imageW + 'px', height: imageH + 'px' }" />
  <div class="ocr-overlay" :style="{ width: imageW + 'px', height: imageH + 'px' }">
    <OcrBox v-for="w in words" :word="w" @dblclick="store.copyWord(w)" />
  </div>
</div>
```

`OcrBox.vue` 直接使用归一化像素坐标（无需换算，overlay 与图片同层同 scale）：

```html
<div class="ocr-box"
     :style="{ left: rect.left + 'px', top: rect.top + 'px',
               width: rect.width + 'px', height: rect.height + 'px' }"
     @mouseenter="hover = true" @mouseleave="hover = false"
     @dblclick.prevent="$emit('dblclick', word)" />
```

```css
.ocr-box { position: absolute; border: 2px solid green; box-sizing: border-box; cursor: pointer; }
.ocr-box:hover { border-color: red; }
```

> 旧代码 `width: loc.width + 2` 是补偿 1px 边框；用 `box-sizing: border-box` 替代即可。

**平移（pan）**：视口 `overflow: auto`，平移 = 改 `scrollLeft/scrollTop`（与 QML Flickable 一致）。
**缩放（Ctrl+滚轮）**：`zoom += deltaY / 1200`，clamp `0.1–5.0`；可选以鼠标位置为锚点。

`src/utils/viewport.ts`（为未来点击定位/框选预留）：

```ts
export function wordToScreen(w: OcrWord, zoom: number, scroll: { x: number; y: number }, offset: { x: number; y: number }) {
  return {
    left: w.rect.left * zoom + offset.x - scroll.x,
    top:  w.rect.top  * zoom + offset.y - scroll.y,
  }
}
```

### 4.4 剪贴板流程

- **复制单词/全部**：`src/utils/clipboard.ts` → `navigator.clipboard.writeText` → 成功入 `copyLog`（复刻旧 `onCopySuccess`）；
- **粘贴图片**：监听 `paste` 事件读 `clipboardData.items` 图片；若 WebView 剪贴板受限，回退到 Rust `arboard` 读位图转 base64 返回（`#[tauri::command] read_clipboard_image`）；
- 首期建议**全部走 Rust `arboard`** 以保跨平台一致，规避浏览器安全策略差异。

### 4.5 图片输入三种方式（复刻旧逻辑）

1. **文件选择**：右键菜单 → `tauri-plugin-opener` 文件对话框（filter png/jpg/jpeg/bmp/gif/webp）→ `loadImage`；
2. **剪贴板粘贴**：见 §4.4；
3. **拖放**：`@dragover/@drop`，校验扩展名，`FileReader.readAsDataURL` → `loadImage`。

### 4.6 图像处理命令

- **修正方向**：`invoke('fix_orientation', { image: base64, angle: 90 })` → Rust `image` crate 旋转 → 返回新 base64 → 重新识别（复刻旧 `fix_orientation` + 自动重识别）；
- **复原图片**：`store.reset()`（zoom=1、滚动归零、居中）；
- **清除图片**：`store.clear()`（清空图片/结果/日志，复刻 `clear_context`）。

## 5. 持久化与配置

**方案：`tauri-plugin-store`（JSON 文件）**。旧 SQLite（WXSQLite 加密包装）对轻量 key-value 配置过重；插件 store 官方维护、Rust 后端直接读写，天然贴合"密钥仅在 Rust 读取"。

**配置结构**（`settings.json`，路径 `%APPDATA%/com.onlytool.app/`）：

```json
{
  "app":   { "theme": "dark" },
  "ocr":   { "activeEngine": "baidu" },
  "engines": {
    "baidu":    { "apiKey": "***", "secretKey": "***" },
    "tencent":  {}
  }
}
```

**Rust 侧封装**（`src-tauri/src/config/mod.rs`）：

```rust
pub struct EngineConfig {
    pub active_engine: String,
    pub secrets: HashMap<String, String>,
}

pub fn load_engine_config(app: &tauri::AppHandle) -> Result<EngineConfig, OcrError> {
    let store = app.store("settings.json")?;
    let active = store.get("ocr.activeEngine").as_str().unwrap_or("baidu").to_string();
    let secrets = store.get(format!("engines.{active}"))
        .and_then(|v| v.as_object())
        .map(|m| m.into_iter()
            .map(|(k, v)| (k.clone(), v.as_str().unwrap_or("").to_string()))
            .collect())
        .unwrap_or_default();
    Ok(EngineConfig { active_engine: active, secrets })
}
```

> **安全提示**：store 为明文 JSON。密钥属于敏感数据，首期用密码框掩码 + 仅 Rust 侧读写；V1.5 评估叠加 `keyring` 系统凭据加密。

## 6. 主题系统（浅色/深色）

- **方案**：CSS 变量（design tokens）定义语义色板，映射旧 Material-3 色板（`ForTheme.py` 中 `backgroundColor`/`surfaceContainerColor`/`onBackgroundColor`/`outlineColor` 等）；

- **OCR 识别框颜色保持语义固定（绿/红）**，不随主题变，与旧行为一致。

## 9. 实现路线（落地顺序）

1. **项目骨架**：初始化 Vite+Vue3+TS 前端、`tauri init` Rust 壳、侧边栏 + `/ocr` 路由 + 主题变量；

7. **打包**：NSIS/MSI 配置 + 图标 + 发布（含 CI）。
