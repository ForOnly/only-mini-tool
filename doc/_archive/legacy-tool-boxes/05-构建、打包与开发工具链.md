# 05 · 构建、打包与开发工具链

> 本章说明依赖管理、PyInstaller 打包、QRC 资源编译、UPX 压缩，以及开发期的热重载与测试脚手架。

## 1. 运行环境

- **平台**：Windows（`windll.shell32.SetCurrentProcessExplicitAppUserModelID`、`.ico`、`.bat`、`sqlite3x64.dll`）。
- **窗口/资源**：Qt Quick Controls 使用 `Basic` 样式；QML 打包进资源后经 `:/imports` 访问。

## 2. 依赖（`requirements.txt`）

|---|---|---|

## 3. PyInstaller 打包（`app.spec`）

| 配置项 | 说明 |
|---|---|
| 入口脚本 | `app.py` |
| `datas` | `tool_boxes/utils/dlls` → 同路径；`db` → `db`；`env.yml` → 根 |
| `excludes` | 剔除大量未用 Qt 模块：`Qt3D*`、`QtCharts`、`QtLocation`、`QtMultimedia*`、`QtPdf*`、`QtQuick3D`、`QtWebEngineCore`、`QtWebSockets`、`QtWebChannel`、`QtVirtualKeyboard`、`QtSpatialAudio`、`QtQuickControls2` 等 |
| `excludes_binaries` | 额外按文件名过滤 `a.binaries`（`_avif`、`opengl32sw`、未用 Controls 样式等），darwin 与其余分支各自一份 |
| `EXE` | `name='app'`、`console=False`（窗口程序）、`upx=True`、`icon=app1.ico`、`strip=False` |
| `COLLECT` | `upx=True` |

```bash
pyinstaller app.spec --noconfirm --clean
```

## 4. QRC 资源编译（`build_resources.py`）

- `generate_qrc(root_dir, qrc_file, prefix="/")`：遍历 `imports/`，生成 `resources.qrc` XML。
- `ensure_qrc_up_to_date(qrc_file, py_file)`：当 `.qrc` 新于 `resources_rc.py` 时调用 `pyside6-rcc -o` 重新编译。
- `app.py` 通过 `import tool_boxes.App.resources_rc` 加载编译后的资源（`qrc:/imports/...`）。

```bash
python build_resources.py
```

## 5. UPX 压缩（`upx_compress.bat`）

1. 用 UPX 5.0.2（`upx\upx-5.0.2-win64`）对 `dist\app` 下所有 `*.dll *.pyd *.exe` 执行 `--best --lzma` 压缩。
2. 删除未使用的 Qt Quick Controls 样式目录：`Fusion`、`Universal`、`Material`，进一步瘦身。

## 6. 开发工具链

### 6.1 两套热重载机制（仅开发态）

| 机制 | 载体 | 范围 |
|---|---|---|
| **Python 侧** | `elements/QMLFolderHotReloader.py::QMLHotReloader` | 监听整个 imports 目录，改动后 `engine.clearComponentCache()` + `loadFromModule("App", entry)` 重载整个模块 |
| **QML 侧** | `elements/FileWatcher.py` + `Pages/.../HotReloadMain.qml` | 监听单个 QML 文件，`onFileChanged` 用 `Loader.setSource(relpath + "?" + Date.now())` 加时间戳破坏缓存重载 |

> `HotReloadMain.qml` 中硬编码了开发者机器上的绝对路径，属本机开发专用。

### 6.2 `FileWatcher`（`elements/FileWatcher.py`）
`@QmlNamedElement("FileWatcher")`，包装 `QFileSystemWatcher`。路径变化/文件变化时 `clean()` 后重新 `addPath`（适配编辑器“改名重存”的保存方式）。
