## 1. 架构概览

### 1.1 调用链

```
Vue tools/ocr + shell
  → api/ocr.ts | api/settings.ts
  → #[tauri::command]
  → services (OcrService / SettingsService)
  → domain + OcrRegistry + dyn OcrEngine
  → repository (settings)
  → infrastructure (sqlite / fs / reqwest)
  → Result<T, AppError>
```

### 1.2 运行时依赖（建议）

| 层 | 选型 | 说明 |
|----|------|------|
| 桌面 | Tauri 2 | 自定义无边框标题栏（`decorations: false`）；Windows 优先 |
| 前端 | Vue 3 + TS + Vite | Composition API；无 Pinia/Router/UI kit |
| 异步 | Tokio | command async |
| HTTP | reqwest + rustls-tls | 百度 OAuth / handwriting |
| 图像 | image crate | 旋转等 |
| 剪贴板 | arboard | 位图/文本；规避 WebView 差异 |
| DB | rusqlite + WAL | settings KV |
| 类型 | ts-rs | Domain → `src/api/generated/` |

工具链推荐 `mise.toml`（Node + Rust）；脚本：`dev` / `build` / `check` / `gen-types`。

## 3. 持久化

### 3.1 库与迁移

- DB：`{app_data_dir}/data.db`（由 `identifier` 隔离，不再叠一层目录名）  
- 迁移：`src-tauri/migrations/*.sql`，启动按版本应用  

**表设计约定（业务表）**：

| 字段 | 说明 |
|------|------|
| `id` | `INTEGER PRIMARY KEY AUTOINCREMENT`，代理主键 |
| `created_at` | 创建时间，`TEXT`，UTC/`datetime('now')` |
| `updated_at` | 更新时间；写入时刷新 |
| 业务唯一键 | 另建 `UNIQUE`（如 `settings.key`），**不以业务键代替 id** |

例外：`schema_version` 为迁移元表，以 `version` 为主键并保留 `applied_at`。

示例（当前 `settings`）：

```sql
CREATE TABLE IF NOT EXISTS settings (
  id         INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
  key        TEXT    NOT NULL UNIQUE,
  value      TEXT    NOT NULL,
  created_at TEXT    NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT    NOT NULL DEFAULT (datetime('now'))
);
```

后续 OCR 等相关表同样遵循该约定。另：`003_scripts.sql` 业务表 `scripts`（`name` UNIQUE；`body` 正文；`workspace_path` / `interpreter_path` 可空；`env_json` / `params_schema_json` / `args_template_json`）；`004_script_venv.sql` 加列 `venv_name`（脚本级 venv 绑定，NULL = 跟随全局链）。

工具脚本库（`domain/settings/scripts` · `get_scripts_settings` / `save_scripts_settings`）：

| 键 | 含义 | 备注 |
|----|------|------|
| `scripts.python_path` | 默认解释器，默认 `python` | 可绝对路径；Windows 上 mise/pyenv shim 在部分目录可能不可用，建议 `py` 或 python.exe 绝对路径；保存时于 venvs 目录探测 `--version` 可用性（mise shim 按目录解析，workspace 能跑不代表 venvs 目录能跑），不可用即拒绝保存；运行时解释器链 4 级（脚本级不可覆盖解释器，仅可选 venv）：脚本绑定 venv > 全局启用 venv（`scripts.venv` 键）> 生效 workspace `.venv`（Windows `Scripts/python.exe`、Unix `bin/python`）> 全局；命名 venv 存放 `{app_data}/venvs/<name>/`，指向不存在静默回落；`scripts.interpreter_path` 列仍在 DB（003）但已不读不写（脚本级解释器覆盖已移除） |
| `scripts.default_workspace` | 默认 cwd | 可空 → app cache 下 default-workspace |
| `scripts.env_json` | 全局 env JSON 对象 | 与脚本 env、参数投影叠加 |
| `scripts.env_prefix` | 参数 env 前缀，默认 `PARAM_` | 校验 `^[A-Za-z_][A-Za-z0-9_]{0,31}$` 非空 |
| `scripts.venv` | 全局启用的命名 venv，空 = 未启用 | 经 `set_setting` 单键写入；仅校验名称不校验存在（解析容错回落） |

执行（`services/scripts` 分工：`validate` 校验纯函数 / `prepare` 运行准备纯函数 + `TempScriptGuard` / `runner` 执行内核 / `mod` 编排 + 单飞策略）：

- **env**：`process_env ∪ global ∪ script ∪ PARAM_*`；**argv**：`args_template.before` → 脚本路径 → 动态 args → `args_template.after`（`before` 含 `-c` 等时可盖掉 body）；**stdin**：`passAs=stdin` 参数以类型化 JSON 写入子进程 stdin（number 整数优先序列化，boolean 原生 bool；无 stdin 参数写 `{}`），独立写任务避免大参数阻塞。
- 临时 `.py` 写 `{app_cache}/scripts-run/`（**不写**用户 workspace；`TempScriptGuard` Drop 删除，每次 run 前清理孤儿 `run-*.py` 兜底 app 崩溃残留）。**参数模块**：每次 run 同目录生成固定名 `onlytool_params.py`（`render_params_module`：schema → frozen dataclass `Params` + 预填实例 `params`；类型映射 str/`Union[int,float]`/bool/`Literal[选项]`/`Path`；required 无默认字段在前；值/选项 Python 字面量转义；number NaN/Inf 特判 `float("nan")`；Python 关键字 key codegen 追加 `_` 且保存校验拒绝；空 schema 生成 `pass` 空类）——脚本经 `sys.path[0]` 直接 `from onlytool_params import params`；guard Drop 与孤儿清理随脚本一并删除；`before` 含 `-c`/`-m`/`-I` 时通道失效（契约注明）。
- cwd 相对路径相对**进程 cwd**（建议绝对路径）；不存在时 `create_dir_all`。硬编码超时 **300s**（超时 kill，stderr 追加说明）。取消：`Ok(ScriptRunResult{ cancelled: true })`，无 `scripts.cancelled` 错误码。
- **执行内核（runner）**：`CancellationToken` 取消（无轮询无竞态，pre-spawn 取消直接返回空结果）；stdout/stderr 各由独立 reader 并发流式读取（防 pipe 写满死锁），`LimitedOutput` head 768KiB + tail 256KiB（VecDeque 淘汰最旧，traceback 保末尾），**超限继续读但丢弃**，内存上限恒定 ≈1MiB/流；杀树 Windows `taskkill /T /F`、Unix SIGKILL，kill 后 wait 10s 兜底、reader 汇合 5s grace + abort。
- **单飞**：`ScriptRunRegistry`（run_id → token，`std::sync::Mutex<HashMap>`）锁内原子 check+insert，策略在 service 层表达，内核无感知。
- **参数校验**：key 字符集 `^[A-Za-z_][A-Za-z0-9_]{0,63}$`（env/argv 双安全，仅保存时校验，存量不重校）；default 与类型匹配（number 可解析、select 属于选项）；运行时在 default 兜底后的有效值上校验。
- **编码**：输出解码 UTF-8 优先、非 UTF-8 回退 **GB18030**（GBK 超集；中文 Windows Python <3.15 管道默认 cp936）；env 未设 `PYTHONIOENCODING` 时自动注入 `utf-8`（大小写不敏感检查，任一层显式设置则尊重），使 Python 管道 stdio 与工具统一 UTF-8（stdin JSON 通道一致）。已知限制：混合编码流（GBK 混子进程 UTF-8 原始字节）整体按 GB18030 解码。
- `ScriptRunResult.command`：等效命令回显（解释器 + args_template + **脚本名** + 动态参数，非临时路径，仅供阅读/复制）。
- `scripts.env_json` 损坏时 `get_scripts_settings` 报 `validation_error`（不静默变空）。CSP 为 Monaco 放行 `worker-src blob:` 与 `script-src 'unsafe-eval'`（仅 editor worker）。
- **诊断 tracing 前缀**（写入 `app.log`，设置页日志面板可 grep）：`[scripts.format]`（chain=`workspace .venv`|`global python`；成功/失败 kind=missing|broken|other/超时）、`[scripts.run]`（解释器链/等效命令/结束含 exit·elapsed；绑定 `.venv` 走默认 workspace）、`[scripts.venv]`（create start/ok/failed/cleanup、pip install start/finished）。

日志文件：`{app_data_dir}/logs/app.log`（始终写入；级别 INFO，调试开启启动后为 DEBUG）。

调试入口：`app.debug_enabled=true` 时，设置页调试面板提供「打开开发者工具」按钮 → `open_devtools`。桌面守卫仍全局 `preventDefault` 禁用浏览器默认右键（不弹出调试菜单、无快捷键呼起）。Cargo 启用 `devtools` feature；运行时仍 `require_debug`。

安全说明：OCR **密码字段**存 OS keyring（`infrastructure/secret_store`，Windows Credential Manager）；读取时若库内仍有明文则迁移并清空。`ocr.settings_version` wipe 时同步 `wipe_engine_secrets_on_schema_reset`。`get_ocr_settings` 仍向配置页回传密码明文（便于编辑；不落盘）。非密钥 KV 仍明文 + OS 目录 ACL。

## 4. OCR 子系统

### 4.1 域模型（ts-rs 导出）

概念字段（Rust domain，serde camelCase）：

```text
OcrRect   { left, top, width, height }   // 图片像素坐标
OcrWord   { text, rect, confidence?, line? }
OcrResult { engine, words, text }
```

- `text`：便捷全文（如 `words` 换行拼接）。  
- 百度无 confidence 时归一为 `1.0`。  
- **禁止**前端另维护一套长期分叉的结果类型；以 generated 为准。

### 4.2 引擎抽象

目录：`services/ocr/{config,registry,service}.rs` + `services/ocr/engines/{baidu,paddle}.rs`。

```text
#[async_trait]
trait OcrEngine {
  fn spec(&self) -> &'static EngineSpec;  // id + fields(name/required/kind)
  async fn recognize(&self, image: &[u8], cfg: &EngineConfig) -> Result<OcrResult, AppError>;
}

EngineConfig { values: HashMap<field, String> }  // 短名；仅后端组装
OcrRegistry::global()  // OnceLock；engines::register_all()
```

**设置键（ocr.*）**：

| Key | 说明 |
|-----|------|
| `ocr.settings_version` | 当前 `2`；启动不符则 wipe `ocr.*` + keyring 密码字段 |
| `ocr.active_engine` | 默认 `baidu`；以 Registry 为准 |
| `ocr.timeout_ms` | 全局超时（默认 `60000`，适配异步引擎） |
| `ocr.inspector_placement` | `left` \| `right` \| `bottom`（默认 `right`） |
| `ocr.engine.<id>.<field>` | 如 `ocr.engine.baidu.api_key`、`ocr.engine.paddle.access_token` |

厂商 JSON **仅**在对应 `engines/<id>.rs` 解析 → `OcrResult`；Registry/Service 不做多厂商 if/else。

Baidu：OAuth → handwriting → `words_result`；**进程内** `access_token` 缓存（按 api_key/secret_key + `expires_in` 提前 120s；密钥变更或 error 110/111 失效并重试一次）。

Paddle（官方在线 API）：AI Studio Access Token；`POST/GET https://paddleocr.aistudio-app.com/api/v2/ocr/jobs` 异步提交/轮询；`done` 后 **无鉴权** 下载 `resultUrl.jsonUrl`（JSONL）→ `result.ocrResults[].prunedResult` 的 `rec_texts` / `rec_boxes`。字段：`access_token`（必填）、`model`（可选，默认 `PP-OCRv5`）。

设置 IPC：`get_ocr_settings` / `save_ocr_settings`（描述符 + 值一次往返；FE 按 field 渲染；i18n 约定 `settings.ocrEngine_${id}` / `settings.ocrField_${name}`）；密码字段经 keyring 读写。

### 4.3 Service 与 Command

| Command（示意名） | 行为 |
|-------------------|------|
| `recognize_image` | 参数：`path`；读文件 → Registry → 超时（默认 60s）→ `OcrResult`；**无** key 参数；可与 `cancel_recognize` 竞态取消 |
| `cancel_recognize` | 取消进行中识别（无任务 no-op）；释放单飞锁 |
| `get_ocr_settings` | 返回引擎列表 + 字段描述 + 当前 values（密码自 keyring） |
| `save_ocr_settings` | 写 active/timeout + **仅当前引擎**字段；密码写 keyring；校验 key 归属 |
| `rotate_image_orientation` | path + 角度 → 旋转写回/新临时文件 → 返回新 path |
| `stage_image_file` | 用户文件拷入 `app_cache_dir/ocr/` |
| `stage_image_bytes` | Web paste 等内存图片写入临时文件 |

### 5.3 滚动条

- **方案**：全局 `::-webkit-scrollbar` 伪元素（`styles/base.css`）——WebView2 固定 Chromium 零风险；圆角胶囊细条 + 透明轨道 + thumb hover 变深只有伪元素可做。token 见 §5.2（`--scrollbar-*`，thumb 派生自 `--text-muted` 随主题切换）。
- **变体**：窄容器加 `data-scrollbar="thin"` 属性（6px）；全局属性选择器，特异性恒胜默认，新增滚动容器自动继承默认样式、无需登记。
- **页面约定**：设置页/工具配置页 `scrollbar-gutter: stable both-edges`（720px 列永久居中不跳，保「滚动条贴窗右」裁定）；设置页调试日志 pre 加 `overscroll-behavior: contain`（全项目唯一真实滚动链）；thin 用于：调试日志、脚本编辑左栏、脚本日志面板、OCR 检查器三 tab。Monaco 自绘 DOM 条不吃 CSS 伪元素，经 option 对齐（`scrollbar.verticalScrollbarSize/horizontalScrollbarSize: 10` 对齐 `--scrollbar-size`，`useShadows: false` 去投影）。
- **禁令**：全项目**永不**引入标准 `scrollbar-width` / `scrollbar-color`——Chromium 121+ 会静默覆盖伪元素方案。
- **行为说明**：自定义伪元素会禁用 WebView2 可能启用的 overlay/fluent 滚动条，强制经典占位式——这是可预测性的来源而非兼容性损失。thumb 仅颜色过渡、无运动学内容，故不设 `prefers-reduced-motion` 分支。
- **非目标**：原生 `<select>` 下拉弹层（不可样式化）。

## 6.5 终端子系统与通用编辑器模块（v0.3.0）

### 6.5.1 终端（xterm.js + ConPTY）

**硬性约束**：不弹任何系统控制台窗口、不依赖用户安装终端软件——shell 进程（pwsh/powershell/cmd，Windows 自带）无窗口挂在 ConPTY 上，由应用内 xterm.js 渲染。

**Rust（`services/terminal/`）**：`portable-pty 0.8` 打开 ConPTY；`TerminalRegistry` 全局会话表（上限 16，**不进脚本单飞**——多会话并发）；每会话 3 线程：reader（阻塞读 8KB→mpsc）→ broadcaster（`recv_timeout(8ms)` 合并窗口、单帧 ≤64KB 切分 → `Utf8Accumulator` 增量解码（跨 chunk 劈开的多字节扣留到下轮，非法序列 U+FFFD；GBK 输出为已知限制）→ scrollback 环形（256KiB 字节预算）→ Channel 广播；EOF 冲刷并发 Exit）+ waiter（记录退出码）。锁序 subscribers→scrollback，attach 快照+注册持锁（回放无间隙不重复）；Channel 发送失败自愈剪枝。dispose 复用 runner 的 `kill_tree`（taskkill /T /F）；`RunEvent::Exit → dispose_all()` 防 conhost/shell 残留。

**venv 激活（env 注入式，不执行 Activate.ps1）**：`VIRTUAL_ENV` + PATH 前插 `Scripts/` + `PYTHONUTF8=1`；编码统一与 venv 徽标提示符经**启动参数**注入（v0.3.1 起）：pwsh/powershell `-NoLogo -NoExit -EncodedCommand base64(UTF-16LE)`（Output/InputEncoding + prompt 函数，零 stdin 写入=零回显零竞态）；cmd `/k @chcp 65001>nul`；用户自定义 `init_commands` 仍走延迟写入（显式 opt-in，会回显）。终端 env 全量继承系统环境 + 追加（与 runner 的 env_clear 白名单刻意相反）。无 `deactivate` 命令（已知取舍）。

**子进程 spawn 纪律（v0.3.1 根因修复）**：GUI 父进程（`windows_subsystem="windows"`）flags=0 spawn 控制台子进程会**每次新分配 console**——高频叠加 ConPTY 资源累积后在 CSRSS/conhost 初始化阶段间歇失败（`STATUS_DLL_INIT_FAILED 0xC0000142`，实测终端会话存活期间 format 连续失败）且每次闪窗。全仓库 spawn 点（runner/format/probe/kill_tree）经 `infrastructure::process::no_window*` 统一加 `CREATE_NO_WINDOW`（stdio 全管道零语义损失）；format 补 `kill_on_drop`。

**前端 kit（`src/components/terminal/`）**：`xtermLoader`（动态 import 单例，@xterm 系独立异步 chunk ~291KB/gzip 73KB + CSS 4KB，主包零重依赖）；`TerminalView`（单会话核心：attach 回放/ResizeObserver 100ms 防抖 fit/退出覆盖层/`attachOnly` 只附着模式/智能复制粘贴——Ctrl+C 有选区复制无选区 ^C、Ctrl+V 粘贴、右键复制粘贴清屏菜单；unmount 只 detach 不销毁；字体 Cascadia Mono 栈 + `--terminal-bg` 专属底色）；`TerminalTabs`（多会话标签宿主：v-show 保挂载、「+」新建通用 shell、标签关闭即 dispose、`disposeAllTabs/releaseAllTabs` 供宿主管生命周期）；`useTerminalSessions`（key→id 登记表，in-flight 去重，**Exit 后 10s 自动回收**）。标签样式统一走 `common/AppTab.vue`。

**会话归属与回收（v0.3.1 语义）**：会话记录归属窗口 label——非 main 窗口 attach 即取得归属（`attach_owner`），`WindowEvent::Destroyed → dispose_owned_by` 自动回收（覆盖子窗 webview 异常消亡）；`RunEvent::Exit → dispose_all` 兜底。dispose = kill_tree + 立即关闭 PTY（take master/writer）——reader 必得 EOF、线程必然退出（根治孙进程幸存泄漏）。编辑页 dock 会话键含环境指纹 `script:<id>:<venv|global>:<cwd>`（挂载期间切脚本/换绑定销毁重建，同环境往返列表保留回放）；设置页会话随页面走（离开设置页销毁；拖出后 `releaseAllTabs` 移交子窗）。Exit 事件含退出码（waiter 先写 code 再置 exited，broadcaster 小窗口等待）；**Resize 事件广播采纳式同步**（接收方对齐显示尺寸不回发，防双视图折行错乱/乒乓）。

**接入点**：编辑页底栏「运行日志 | 终端」标签页（`resolve_script_terminal` 复用 run 解析链：cwd + venv 徽标）；设置页 venv 行「终端」→ 展开区 TerminalTabs（收起不销毁）。
